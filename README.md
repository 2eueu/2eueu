  ## ⚽ Featured Project
  
  ### [Football Scout AI](https://github.com/2eueu/football-scout-ai)
  &nbsp;·&nbsp; [Live Demo 
  →](https://football-scout-ai-kujc5juarc7gdz4vhwaapb.streamlit.app/)

  > End-to-end ML platform for scouting undervalued players across Europe's Big
  5 leagues 
  
  - **3,435 players · 5 leagues · 4 seasons** of weighted FBref + Understat data
  - Position-specific **XGBoost** value models (CV RMSE 0.54–0.55, ~R² 0.85) —
  competitive with published academic benchmarks
  - 24 engineered features: xG/xA, contract years remaining, team prestige,
  age×contract interaction
  - **Natural language search** via Llama 3.3 70B (Groq) — *"clinical striker 
  under 25 in Ligue 1"*
  - Temporal backtest quantifies **~43% RMSE improvement** from multi-season
  weighting vs single-season baseline
  - PDF scout reports with embedded radar charts · Watchlist · Cosine-similarity
   player finder
  
  Stack: Python · XGBoost · SQLite · Streamlit · Plotly · PyTorch · Groq API
